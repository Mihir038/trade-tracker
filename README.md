# Trade Tracker

A static trading journal hosted with GitHub Pages.

## Data and privacy

The app saves trades, notes, settings, and attached chart images in this browser's local storage. That data is not uploaded to GitHub or shared between browsers. Export a backup from the app before clearing browser data.

The deployed website is public. Do not enter information you do not want stored in your browser.

## Deployment

Every push to `main` deploys the site through GitHub Pages. The repository's Pages build source must be set to **GitHub Actions**.
